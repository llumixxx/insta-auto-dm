# 인스타 자동 DM (댓글 → DM)

모델 계정 게시물에 키워드 댓글이 달리면 자동으로 DM과 대댓글을 보내요.
여러 계정을 한 관리 페이지에서 관리할 수 있어요. Vercel과 Upstash 무료 플랜으로 돌아가요.

```
api/connect.js       모델 연결 링크 → 인스타 로그인
api/callback.js      로그인 완료 → 토큰 저장 + 댓글 웹훅 구독
api/webhook.js       댓글 수신 → 키워드 매칭 → DM + 대댓글
api/accounts|rules|media|logs.js   관리 페이지용 API
api/cron-refresh.js  매일 토큰 자동 연장 (60일 만료 방지)
index.html           관리 페이지
privacy.html         개인정보처리방침 (메타 앱 라이브 전환에 필요)
```

---

## 1. GitHub에 올리고 Vercel 배포

1. 이 폴더를 GitHub 새 레포에 올려요.
2. Vercel → **Add New → Project** → 레포 선택 → **Deploy**를 눌러요. 처음 배포는 에러가 나도 괜찮아요.
3. 배포 주소를 메모해둬요. 예: `https://insta-auto-dm.vercel.app`

## 2. DB 연결 (Upstash Redis)

1. Vercel 프로젝트 → **Storage** 탭 → **Upstash for Redis** → Create(무료 플랜) → 프로젝트에 연결해요.
2. `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동으로 들어가요.

## 3. 메타 앱 만들기

1. https://developers.facebook.com → **내 앱 → 앱 만들기**
2. 사용 사례: **"Instagram에서 메시지 및 콘텐츠 관리"** 선택 → 앱을 만들어요.
3. 왼쪽 메뉴 **사용 사례 → Instagram API → 맞춤 설정 → API 설정(Instagram 로그인)** 으로 들어가요.
4. 화면 위쪽의 **Instagram 앱 ID / Instagram 앱 시크릿 코드**를 복사해둬요. 페이스북 앱 ID가 아니라 *Instagram* 앱 ID예요.
5. **"3. 비즈니스 로그인 설정"** → 리디렉션 URL에 다음 주소를 넣어요.
   `https://내주소.vercel.app/api/callback`
6. **"2. 웹훅 구성"**
   - 콜백 URL: `https://내주소.vercel.app/api/webhook`
   - 확인 토큰: 관리 페이지 **⚙️ 메타 앱 설정값**에 나온 값
   - 4단계 환경변수를 넣고 재배포한 다음에 **확인 및 저장**을 눌러야 성공해요.
   - 필드 목록에서 **comments** 구독을 켜요.
7. **앱 설정 → 기본 설정**
   - 개인정보처리방침 URL: `https://내주소.vercel.app/privacy.html`
   - 카테고리를 선택하고 저장해요.
8. 위쪽 **앱 모드**를 **라이브**로 바꿔요. 개발 모드에서는 실제 댓글 웹훅이 안 와요.

## 4. Vercel 환경변수

| 이름 | 값 | 비밀? |
|---|---|---|
| `META_APP_ID` | 메타 앱 ID (앱 설정 > 기본 설정) | 아님 |
| `META_LOGIN_CONFIG_ID` | 통합 로그인 구성 ID | 아님 |
| `META_APP_SECRET` | 앱 시크릿 코드 (앱 설정 > 기본 설정 > 보기) | **비밀** |
| `ADMIN_PASSWORD` | 관리 페이지 비밀번호 | **비밀** |
| `BASE_URL` | 배포 주소 | 아님 |

※ 2026년 10월 이후 만든 메타 앱은 'Instagram 로그인'을 못 쓰고 **통합 로그인**(Facebook Login for Business + 구성 ID)만 돼요.
`META_LOGIN_CONFIG_ID`가 있으면 자동으로 통합 로그인 방식으로 동작해요. 토큰 만료도 없어요.
예전 앱(Instagram 로그인)이면 `META_LOGIN_CONFIG_ID` 없이 `IG_APP_ID`/`IG_APP_SECRET`로 쓰면 돼요.

웹훅 확인 토큰, 모델 연결 코드는 자동이에요 → 관리 페이지 **⚙️ 메타 앱 설정값**에서 확인.

## 5. 모델 계정 연결

앱 심사를 안 받고 쓰는 방법이에요. 모델을 테스터로 등록해요.

1. 메타 앱 → **앱 역할 → 역할 → Instagram 테스터 추가** → 모델 인스타 아이디를 입력해요.
2. 모델 쪽에서 할 일: 인스타 웹(instagram.com) → **설정 → 앱 및 웹사이트 → 테스터 초대** → **수락**
3. 관리 페이지(`https://내주소.vercel.app`) → **모델 연결 링크 복사** → 모델에게 보내요.
4. 모델이 링크를 열고 인스타 로그인 → **허용**을 누르면 관리 페이지에 계정이 나타나요.

※ 모델 계정은 **프로페셔널 계정**(크리에이터/비즈니스)이어야 해요.
※ 모델 인스타 앱의 **설정 → 메시지 및 스토리 답장 → 메시지 컨트롤 → 연결된 도구 → 메시지 액세스 허용**도 켜져 있어야 DM이 나가요.

## 6. 사용법

1. 관리 페이지에서 계정을 선택하고 **+ 규칙 추가**를 눌러요.
2. 게시물 선택(또는 모든 게시물) → 키워드 입력 → 보낼 DM 입력 → (선택) 대댓글 입력 → 저장해요.
3. 다른 계정으로 그 게시물에 키워드 댓글을 달아서 테스트해요.
4. **발송 기록** 탭에서 성공/실패를 확인해요.

## 메타 제한 (어떤 툴이든 똑같아요)

- 댓글 하나당 DM은 1번만 보낼 수 있어요.
- 댓글이 달린 뒤 7일 안에만 보낼 수 있어요.
- 추가 메시지는 상대가 답장한 뒤 24시간 안에만 보낼 수 있어요.
- 같은 키워드에 여러 규칙이 걸리면 목록 맨 위 규칙 하나만 적용돼요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 웹훅 확인 및 저장 실패 | 환경변수 넣고 재배포했는지, 확인 토큰이 같은지 |
| 댓글 달아도 아무 반응 없음 | 앱이 **라이브** 모드인지, 웹훅 **comments** 구독이 켜져 있는지, 모델이 테스터를 수락했는지 |
| 발송 기록에 DM 실패 | 모델 계정의 **메시지 액세스 허용**이 켜져 있는지, 댓글이 7일 지났는지 |
| 계정에 "토큰 갱신 실패" | 연결 링크를 다시 눌러서 재연결 |
